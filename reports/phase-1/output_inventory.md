# Phase 1 Output Inventory

This document serves as an exhaustive inventory of all serialized data blocks generated by the Phase 1 Video Processing engine.

## 1. Annotated Videos (`outputs/detection/videos/`)
- Contains visually rendered MP4 files mimicking the exact input parameters (4K, ~15 FPS) but with YOLOv8 inference bounding boxes and ByteTrack tracking IDs permanently stitched into the frame.
- **Example Asset:** `Copy of Hafidz 2 Store-Picking and Putting-1_annotated.mp4`

## 2. Detection JSON (`outputs/detection/json/`)
- Pure structured serialization of the tracking engine output. One standard file per video natively, and one track-specific file.
- **Example Assets:** 
  - `Copy of Hafidz 2 Store-Picking and Putting-1.json` (Detection list)
  - `Copy of Hafidz 2 Store-Picking and Putting-1_tracks.json` (Track mappings)

## 3. Detection CSV (`outputs/detection/csv/`)
- Tabular representation of the JSON payloads intended for Pandas analysis.
- **Example Assets:**
  - `Copy of Hafidz 2 Store-Picking and Putting-1.csv`
  - `Copy of Hafidz 2 Store-Picking and Putting-1_tracks.csv`

## 4. Metadata Files (`outputs/detection/reports/`)
- High-level properties extracted dynamically from the `datasets/` repository prior to processing.
- **Example Assets:**
  - `metadata.json`
  - `metadata.csv`

## 5. Logs (`outputs/logs/`)
- Continuous telemetry output files ensuring system observability.
- **Assets:**
  - `processing.log` (Engine progression states)
  - `error.log` (Fatal execution traps)
  - `performance.log` (Reserved for downstream latency analytics)

## 6. Reports (`reports/phase-1/`)
- The documentation core validating the Phase 1 build.
- **Assets Generated:**
  - `tracking_metrics.md`
  - `environment_report.md`
  - `json_schema.md`
  - `api_validation.md`
  - `project_structure.md`
  - `acceptance_checklist.md`
  - `phase2_compatibility.md`
  - `performance_metrics.md`
  - `output_inventory.md`
  - `final_phase1_report.md` (Executive conclusion)

## 7. API Outputs
- Real-time synchronous HTTP responses provided by `backend/main.py`.
- **Assets Evaluated:**
  - JSON Job States (`{"status": "Pending"}`)
  - Result Routing (`{"results_url": "..."}`)
